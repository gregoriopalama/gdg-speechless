# Task T1.2: Firebase Integration and Configuration

## Descrizione
Configurare l'integrazione di Firebase nel progetto React, configurando Firebase CLI per Hosting ed impostando l'inizializzazione del client SDK.

## Dettagli Tecnici
* Inizializzare la configurazione Firebase nel workspace (`firebase.json`, `.firebaserc`).
* Implementare `src/firebase/config.ts` per inizializzare l'app Firebase leggendo le credenziali da variabili d'ambiente (`.env`).
* Configurare Firebase Firestore (regole iniziali `firestore.rules`).

## Criteri di Accettazione (Acceptance Criteria)
* [x] **AC-T1.2.1:** L'applicazione deve essere ospitata ed eseguita localmente tramite Firebase Hosting simulator (`firebase serve` o equivalente npm script) (rif. AC-01.2).
* [x] **AC-T1.2.2:** Le variabili d'ambiente di Firebase sono modellate ed iniettate correttamente tramite il file `.env` e lette in sicurezza senza esposizione di credenziali statiche nel codice sorgente.
