# Task T3.2: Nano Banana Integration (Slides)

## Descrizione
Sviluppare l'integrazione con il generatore di immagini Vertex AI (modello `gemini-3.1-flash-lite-image`) per creare i file visivi delle slide in tempo reale.

## Dettagli Tecnici
* Implementare il servizio di generazione immagini tramite l'SDK Vertex AI configurando il modello `gemini-3.1-flash-lite-image` (noto anche come Nano Banana 2 Lite).
* Configurare la logica di prompt generation:
  * Per *Beginner*, comporre il prompt usando le `keywords` generate da Gemini.
  * Per *Legend*, comporre il prompt in modo casuale ed astratto, scollegato dal tema.
  * Se configurato lo stile grafico dell'host (es. "Cyberpunk"), accodarlo al prompt (es. `", cyberpunk style"`).
* Gestire il ritorno dell'URL dell'immagine generata.

## Criteri di Accettazione (Acceptance Criteria)
* [x] **AC-T3.2.1:** Le slide generate da `gemini-3.1-flash-lite-image` devono riflettere lo stile grafico configurato a livello globale dall'host (rif. AC-03.3).
* [x] **AC-T3.2.2:** Le immagini per il livello Legend non devono avere alcuna attinenza logica con il tema della presentazione.
