# Task T3.1: Vertex AI Gemini Integration (Themes)

## Descrizione
Sviluppare la logica di integrazione con Vertex AI per la generazione automatica dei temi/titoli delle presentazioni tramite Gemini.

## Dettagli Tecnici
* Configurare Vertex AI SDK per l'uso del modello Gemini (es. `gemini-3.6-flash`).
* Scrivere il prompt di sistema (System Instructions) dinamico per Gemini includendo:
  * Livello di difficoltà selezionato (Beginner, Intermediate, Advanced, Legend).
  * Seed dell'evento impostato dall'host.
  * Lingua del round (IT/EN).
* Configurare le opzioni di risposta per forzare l'output in formato JSON strutturato contenente il titolo (`theme`) e le parole chiave (`keywords`).

## Criteri di Accettazione (Acceptance Criteria)
* [ ] **AC-T3.1.1:** Gemini deve generare titoli coerenti con la lingua selezionata (se IT generare in italiano, se EN generare in inglese) (rif. AC-03.1).
* [ ] **AC-T3.1.2:** Se impostato, il seed inserito dall'host deve influenzare semanticamente o essere presente all'interno del titolo generato (rif. AC-03.2).
* [ ] **AC-T3.1.3:** L'output deve essere parsato correttamente nel formato JSON previsto (`theme` e `keywords`).
