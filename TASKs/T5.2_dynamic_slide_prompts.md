# Task T5.2: Dynamic Slide Prompts Generation (Gemini)

## Descrizione
Eliminare i soggetti hardcoded per la generazione delle immagini delle slide ed integrare la generazione dinamica dei soggetti dei prompt (slidePrompts) direttamente all'interno della chiamata Gemini per la generazione del tema. 

## Dettagli Tecnici
1. **Firestore Schema (`src/firebase/services.ts`):**
   * Aggiungere `slidePrompts?: string[]` all'interfaccia `RoundState`.
   * Inizializzare `slidePrompts: []` all'interno di `DEFAULT_SESSION_STATE`.
2. **Gemini Engine (`src/firebase/gemini.ts`):**
   * Aggiornare `GeneratedThemeResponse` per includere l'array `slidePrompts: string[]`.
   * Estendere `generateSpeechlessTheme` per accettare `slidesCount: number`.
   * Aggiornare l'istruzione di sistema per richiedere la generazione di un array JSON `slidePrompts` di dimensione esatta `slidesCount` contenente descrizioni in lingua inglese dei soggetti per ciascuna slide.
   * Specificare le regole di generazione dei soggetti in base alla difficoltà (Beginner = correlati al tema, Intermediate = parzialmente correlati, Advanced/Legend = totalmente causali e scorrelati).
3. **Flusso UI (`src/pages/SpeechlessView.tsx`):**
   * Passare `currentRound.totalSlides` come parametro alla funzione `generateSpeechlessTheme`.
   * Salvare l'array `slidePrompts` in Firestore durante l'aggiornamento del round nello stato `INTRO`.
   * Passare l'array `slidePrompts` all'hook `useImagePreload`.
4. **Hook Caricamento (`src/hooks/useImagePreload.ts`):**
   * Accettare `slidePrompts?: string[]` nelle props dell'hook.
   * Rimuovere gli array hardcoded `subjects` e `actions`.
   * Modificare `buildPromptForSlide` per attingere direttamente al soggetto descritto in `slidePrompts[index]`.
   * Se non è impostato uno stile globale dall'host, aggiungere in coda a ciascun prompt una tecnica artistica scelta a caso da un array locale di stili (es. *oil painting*, *claymation*, *pop art*, *synthwave*) per mantenere variabilità visiva.

## Criteri di Accettazione (Acceptance Criteria)
* [ ] **AC-T5.2.1:** La risposta del motore di generazione temi Gemini deve contenere il tema e l'array esatto di soggetti per le slide (`slidePrompts`).
* [ ] **AC-T5.2.2:** La web app deve salvare i soggetti delle slide in Firestore/RAM.
* [ ] **AC-T5.2.3:** L'immagine di ciascuna slide deve essere generata partendo dal soggetto dinamico corrispondente fornito da Gemini, arricchito con uno stile casuale o con lo stile globale dell'host.
* [ ] **AC-T5.2.4:** Il livello Beginner deve mostrare una chiara pertinenza tematica tra le slide generate e il tema annunciato, mentre il livello Legend deve mostrare totale scorrelazione e assenza di ripetizioni.
