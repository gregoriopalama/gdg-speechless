# Task T2.3: Admin Panel Route and Config Interface

## Descrizione
Creare l'interfaccia di amministrazione dell'host raggiungibile alla rotta `/admin` per permettere la configurazione dei parametri di sessione.

## Dettagli Tecnici
* Implementare il componente `AdminPanel.tsx`.
* Creare i controlli UI per impostare:
  * Seed dell'evento (input di testo/keyword).
  * Lingua globale (dropdown IT/EN).
  * Numero di slide (input numerico con validazione).
  * Stile visivo delle slide (selettore con opzioni: Default, Cyberpunk, Pixel Art, Watercolor, ecc.).
* Creare una sezione di diagnostica/comandi rapidi per resettare la sessione di gioco o terminare un round.

## Criteri di Accettazione (Acceptance Criteria)
* [ ] **AC-T2.3.1:** L'interfaccia `/admin` deve essere isolata e non accessibile dalle normali azioni della dashboard giocatore `/` (rif. AC-02.3).
* [ ] **AC-T2.3.2:** Tutte le modifiche fatte sui campi di input di `/admin` devono aggiornare il database Firestore in tempo reale o alla pressione di un pulsante dedicato di salvataggio.
