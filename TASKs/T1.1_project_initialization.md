# Task T1.1: Project Initialization and Directory Structure

## Descrizione
Inizializzare l'applicazione React con Vite e TypeScript, configurando la struttura iniziale delle cartelle come descritto in SPEC001.

## Dettagli Tecnici
* Configurare il compilatore TypeScript e il bundler Vite.
* Creare l'albero delle cartelle principali (`src/components`, `src/pages`, `src/hooks`, `src/context`, `src/firebase`, `src/i18n`).
* Configurare il file `.gitignore` per escludere file temporanei, build e credenziali sensibili.

## Criteri di Accettazione (Acceptance Criteria)
* [x] **AC-T1.1.1:** L'applicazione React compila senza avvertimenti o errori tramite il comando `npm run build` (rif. AC-01.1).
* [x] **AC-T1.1.2:** I file locali temporanei di configurazione (`.env`, `node_modules`, `dist`) sono correttamente tracciati all'interno di `.gitignore` (rif. AC-01.4).
