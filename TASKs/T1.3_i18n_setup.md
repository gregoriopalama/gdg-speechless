# Task T1.3: Internationalization (i18n) Setup

## Descrizione
Configurare il modulo di internazionalizzazione dell'applicazione con supporto nativo a Italiano (IT) e Inglese (EN).

## Dettagli Tecnici
* Configurare `react-i18next` e `i18next` in `src/i18n/index.ts`.
* Creare i file di traduzione JSON in `src/i18n/locales/it.json` e `src/i18n/locales/en.json`.
* Integrare il provider i18n in `src/main.tsx` o `src/App.tsx`.

## Criteri di Accettazione (Acceptance Criteria)
* [ ] **AC-T1.3.1:** Al cambio di lingua configurato a livello applicativo (es. tramite un hook `i18n.changeLanguage`), l'interfaccia principale deve ricalcolare e visualizzare tutti i testi localizzati all'istante senza richiedere il refresh della pagina (rif. AC-01.3).
* [ ] **AC-T1.3.2:** I file JSON contengono chiavi coerenti per la gestione del menu principale, delle descrizioni dei livelli e della schermata finale.
