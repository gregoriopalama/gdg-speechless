# Task T3.3: Safety Settings and API Error Fallback

## Descrizione
Configurare i filtri di sicurezza delle API di Vertex AI e implementare la gestione dei fallimenti con schermata di cortesia goliardica.

## Dettagli Tecnici
* Impostare i parametri `safetySettings` per le chiamate Vertex AI (Gemini e Imagen) per minimizzare i falsi positivi dei filtri di sicurezza.
* Scrivere la logica di cattura degli errori (try/catch) sulle chiamate API.
* Sviluppare un componente grafico a tutto schermo che mostra il messaggio di cortesia goliardico in caso di disservizio (es. API limit, errore di connessione, blocco filtro).

## Criteri di Accettazione (Acceptance Criteria)
* [ ] **AC-T3.3.1:** In caso di errore API (es. blocco per safety o timeout), l'applicazione deve mostrare la schermata goliardica di errore entro 10 secondi e consentire al giocatore di premere un pulsante per tornare al menu iniziale in sicurezza (rif. AC-03.4).
* [ ] **AC-T3.3.2:** I filtri di sicurezza sono configurati in modo da non bloccare termini comuni o goliardici non offensivi.
